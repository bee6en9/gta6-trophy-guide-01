Leonida is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: the official list, a saved checklist with export and import, filters, a spoiler setting, a roadmap to the platinum, missable flags, and a cited guide for every trophy.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
